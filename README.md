# OnlyDocker — книга-тренажёр по Docker и Kubernetes

Практический курс: один сквозной проект (.NET minimal API + PostgreSQL + RabbitMQ),
который шаг за шагом упаковывается в контейнеры, собирается в образы, поднимается
Compose-файлом и уезжает в Kubernetes.

Проект — это только «нагрузка». Изучаем Docker и Kubernetes.

## С чего начать

1. Открой [`book/00-план.md`](book/00-план.md) — правила книги, соглашения, оглавление.
2. Дальше по порядку: [`book/00-окружение.md`](book/00-окружение.md) → глава 1 → глава 2 …

## Структура

```
book/
├── 00-план.md                    # правила, соглашения, полное оглавление
├── 00-окружение.md               # глава 0: проверка ОС, железа, сети, прав
├── 01-установка-docker.md        # глава 1: 3 способа установки + полное удаление
├── 02-образы-и-контейнеры.md     # глава 2: 5 способов запустить контейнер
├── 03-жизненный-цикл-и-удаление.md
├── 04-тома-и-сети.md
├── 05-стек-проекта.md
└── assets/app/                   # исходники .NET-приложения для главы 5
```

## Как устроена каждая глава

- **Зачем это в проде** — короткая теория без воды.
- **Возврат в начало** — чек-лист из прошлых глав: команды вводишь сам, ответы под спойлером.
- **Шаги** — команда → что произошло → **проверка** (как убедиться, что сработало).
- **Чек-лист самопроверки** — вопросы, на которые надо уметь ответить командой.
- **Откат** — возврат системы в состояние до главы.
- **Шпаргалка** и **типичные ошибки**.

## Требования к машине

Ubuntu 24.04/26.04 LTS (или аналог с systemd и cgroup v2), x86_64 или arm64,
2+ CPU, 4+ GB RAM, 20+ GB свободного места. Для будущих глав с Kubernetes —
4 CPU, 8 GB RAM, 60 GB. Точные пороги и команды проверки — в главе 0.
